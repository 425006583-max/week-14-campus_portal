# Campus Portal

A simple student web portal developed using Django.

## Project Features
- Home page with a welcome message.
- Announcements.
- Class Schedules.
- Learning Resources.
- About page.
- Shared navigation bar.
- Responsive CSS styling.
- Static image and CSS assets.

## Technologies Used
- Python
- Django
- HTML
- CSS

## How to Run
1. Install Django.
2. Open the project folder in VS Code.
3. Run:

```bash
python manage.py migrate
python manage.py runserver
```

4. Open http://127.0.0.1:8000/ in your browser.
